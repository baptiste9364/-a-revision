# -a-revision

Ce dépôt contient l'OS de la calculatrice NumWorks (Epsilon) en tant que sous-module.

## NumWorks Epsilon

Le sous-module `epsilon` pointe vers [numworks/epsilon](https://github.com/numworks/epsilon), le système d'exploitation open source de la calculatrice NumWorks.

Pour initialiser le sous-module après un clone :

```bash
git submodule update --init --recursive
```
